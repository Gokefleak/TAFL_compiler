# TAFL_compiler

Учебный компилятор для языка разрабатываемый в рамках курса по теории автоматов и формальных языков.

## Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) (C# 14)

## Сборка и запуск

```bash
# Сборка решения
dotnet build

# Запуск модульных тестов
dotnet test
